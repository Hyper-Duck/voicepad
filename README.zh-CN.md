# Voicepad · 本地配音工作台

[English](README.md)

需要 **Python 3.10+** 与 **Chrome / Edge**。界面为简体中文。

Windows 双击 **Start-Voicepad.cmd**，会在默认浏览器打开。也可以运行：

```sh
python server.py --open
```

macOS / Linux 使用 `python3 server.py --open`。

只使用 Python 自带库和浏览器，不需要 npm、FFmpeg、模型或其他安装包。
首次打开是空白 session，导入自己的视频和 SRT 即可开始。仓库不包含个人媒体或录音。

## 操作

1. 顶部 **新建 session** 可以沿用当前视频和字幕，也可以取消勾选从空白开始。旧 session 不会覆盖，通过顶部下拉框切换。
2. **导入视频**、**导入 SRT**。文件复制到本地工作目录，原文件不修改。
3. 右侧点一句字幕跳转；起止时间直接编辑，可填 `00:01:23.456` 或秒数 `83.456`。左侧大字提词显示当前句、下一句，以及距开始/结束的倒计时。
4. **录音模式**：不播放旧人声。选好麦克风，点 **开始录音** 连续录，或点某句的 **录这一句**。默认 1.5 秒准备，显示三个圆点，每 0.5 秒消失一个，可关闭。逐句录音自动在结束时间停止；连续录音点 **停止录音** 结束。
5. **重放模式**：视频、字幕、已录人声同步播放。点每句的 **试听** 也会自动切换到重放。视频原声有独立开关和音量。
6. 每句的 **删除录音** 只删该句。连续录音按字幕自动分段，句间声音也保留，可展开 **查看录音片段** 单独删除。**撤销删除** 可恢复最近 12 次录音修改，包括重录。
7. **导出人声 WAV** 得到独立的人声音轨，48 kHz、16-bit、单声道。开头和句间保留空白，长度至少与视频相同；从 0 秒与视频同时播放即可对齐。视频背景音乐不包含在这个文件内。
8. **导出字幕** 得到编辑后的 SRT。

录音时建议戴耳机，避免背景音乐被麦克风再次录入。第一次录音时，需要在浏览器允许麦克风权限。“↻”可以授权并刷新麦克风列表。点击停止后麦克风会释放，没有麦克风监听或云端上传。

## 时间与重录规则

- 调整某句的开始时间，该句的人声片段同步移动；调整结束时间只改变字幕显示时长，不裁掉已经录好的声音。
- 逐句重录成功保存后，才替换该句的旧录音。
- 连续录音会覆盖本次录音范围内的旧声音，范围以外的旧声音保留。可以撤销。
- 视频缓冲、麦克风断开或暂停时，保存已录部分，防止人声音轨继续走而视频不动。
- 保存失败会显示提示；已生成的录音 WAV 会尝试下载一份备份。不要在“正在保存”或录音时关闭页面。

快捷键：**空格**播放/暂停，**R**开始/停止录音，**Esc**取消准备或停止录音。输入字幕时间或打开弹窗时不会触发快捷键。

## 文件位置

- `data/sessions`：自动保存的 session。
- `data/assets`：导入的视频与原始录音。删除片段是时间轴编辑，保留源录音用于撤销；不要手动删除这些文件。
- `data/exports`：导出的 WAV 与 SRT，同时浏览器也会下载一份。
- 备份整个 `data` 文件夹即可保留所有 session 和素材。
- `Stop-Voicepad.cmd`：退出小型本地服务。先停止录音、等待保存，再关闭服务。

服务仅监听 `127.0.0.1:8768`。关闭网页后服务仍在本机运行，重复启动会重新打开已有服务。没有外部 CDN 或联网依赖。支持浏览器可以解码的视频，推荐 H.264/AAC MP4；导出最长支持两小时。

## 开发与验证

运行：`python server.py --open`

核心算法检查（需要 Node.js 22+，仅用于开发测试）：`node --test tests/core.test.mjs`

本地存储与 HTTP 检查：`python -m unittest discover -s tests -p "test_*.py"`

音频实现参考浏览器官方文档：[AudioWorklet](https://developer.mozilla.org/en-US/docs/Web/API/AudioWorkletProcessor)、[音频定时播放](https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/start)、[离线音轨合成](https://developer.mozilla.org/en-US/docs/Web/API/OfflineAudioContext/startRendering)。
