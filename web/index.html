新建 session

一个干净的人声音轨。之前的 session 随时可以切回来。

只做配音需要的事

  1. 导入视频与 SRT，点一句字幕定位，直接编辑起止时间。
  2. 录音模式不播放已录人声。点“开始录音”连续录；点“录这一句”逐句录。
  3. 重放模式同步播放视频、字幕和人声音轨。视频原声独立开关。
  4. 删错句：每句的“删除录音”只删这句；录音片段列表也可以逐段删除。误删后点“撤销删除”。
  5. 导出人声 WAV保留时间轴上的空白，与视频从 0 秒一起播放即可对齐。导出不包含视频原声。

Session 自动保存在本机。新建不会覆盖旧 session。录音时建议戴耳机；首次使用允许浏览器访问麦克风。

调整字幕起点时，该句录音一起移动；调整终点只改变字幕显示时长。字幕里的 [A] 等说话人标签不会显示在提词正文中。

快捷键：空格 播放/暂停 · R 开始/停止录音 · Esc 取消倒计时或停止录音。请使用 Chrome 或 Edge。
